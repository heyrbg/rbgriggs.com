# rbgriggs.com

R.B. Griggs's personal site. Next.js 15, fully static, deployed by Vercel on every push to `main`.
See README.md for structure and deploy details.

## Content

- `content/originals/`: Substack essays as published. Generated by `npm run import`; never hand-edit.
- `content/essays/`: AI-readable editions. Follow `docs/edition-guide.md`; quotes must be verbatim.
- `content/notes/`: short posts co-written by R.B. and Claude. `draft: true` hides a note from production.
  `idea:` links a note to the idea it develops (`<essay-slug>#<idea-anchor>` from `docs/ideas/`).
- `content/author.md`, `content/overview.md`, `content/bets.md`: bio, offerings, synthesis, current thesis.
- `docs/ideas/`: 213 extracted ideas, one file per essay.

When drafting from R.B.'s words, stay close to them and mark your own additions in the note's top comment.
Notes are co-written with Claude, so they never use first person ("I", "my"); refer to his essays by title.
First person is fine on Work with me and in `content/bets.md`.

## Writing Desk (keep it in sync)

The Writing Desk is a private artifact dashboard of notes and ideas:
https://claude.ai/artifact/Y5mr7yUhHAqd1RegYjWDJo (source: `desk/writing-desk.html`)

After any change to `content/notes/` or `docs/ideas/` is committed:

1. `node scripts/desk-sync.mjs` (writes `.desk/` and `.desk/writes.json`).
2. Read current versions: `ArtifactData list` on `notes`, `ideas` and `meta`.
3. One `ArtifactData batch` from `.desk/writes.json`, adding `if_version` for documents that exist,
   and a `delete` for any note that was removed.

Comments R.B. leaves on a note in the desk and sends to Claude are edit requests for that note's file.
