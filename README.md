# rbgriggs.com

Personal site of R.B. Griggs: speculative philosophy of technology, written for humans and machines.

Every essay from [Tech for Life](https://www.techforlife.com) is published here with an
**AI-readable edition** (summary, thesis, argument, key claims, concepts, objections, FAQ) followed by
the **full original text**. A machine-readable layer is generated from the same content:

| URL | What |
|---|---|
| `/llms.txt` | curated index ([llmstxt.org](https://llmstxt.org)) |
| `/llms-full.txt` | the entire corpus in one markdown file |
| `/essays/<slug>.md` | each essay as a standalone markdown document |
| `/concepts`, `/concepts.md` | glossary of every coined concept |
| `/corpus.json` | structured dataset |
| `/robots.txt` | allows every AI crawler |
| `/sitemap.xml`, `/feed.xml` | sitemap, RSS |

The reasoning behind each choice is in [docs/research-writing-for-ai.md](docs/research-writing-for-ai.md).

## Stack

Next.js 15 (App Router, fully static), React 19, TypeScript. No database, no auth, no client JS needed
to read anything.

```
content/originals/   essays as published (generated by `npm run import`, don't edit)
content/essays/      AI-readable editions (see docs/edition-guide.md)
content/author.md    bio, interests, offerings for /about and /work-with-me
content/overview.md  "The ideas in brief", the author-level synthesis on the home page
lib/corpus.mjs       shared loader used by pages and the build script
lib/site.ts          name, URL, email, social links
scripts/             Substack importer, AI-file generator (runs as `prebuild`)
```

## Develop

```bash
npm install
npm run dev       # http://localhost:4310, live reload, shows drafts
npm run preview   # http://localhost:4320, production build, exactly what Vercel serves
```

The two use separate build folders (`.next-dev` and `.next`), so they can run side by side.

## Post a note

Notes are short, unpolished posts written straight to this site, on any subject.

1. Copy `content/notes/_template.md` to `content/notes/<slug>.md`.
2. Write. Keep `draft: true` while working: drafts show in `npm run dev` but never ship.
3. Delete the `draft` line and push. Vercel publishes the page, its markdown copy, RSS, sitemap and llms.txt entries.

The `summary` line matters most: it's the sentence AI systems are most likely to quote.

## Add a new Substack post

```bash
npm run import -- <slug>
```

Then write `content/essays/<slug>.md` following [docs/edition-guide.md](docs/edition-guide.md).

## Deploy (Vercel + Hover)

1. Push to `github.com/heyrbg/rbgriggs.com`.
2. In Vercel, **Add New → Project → Import** the repo. The defaults (Next.js, `npm run build`) are correct; no env vars needed.
3. In Vercel, **Settings → Domains**: add `rbgriggs.com` and `www.rbgriggs.com`.
4. In Hover, **DNS** for rbgriggs.com: remove the existing parking/forwarding records, then add the records Vercel shows (typically `A @ 76.76.21.21` and `CNAME www cname.vercel-dns.com`).
5. After it's live: submit `https://rbgriggs.com/sitemap.xml` to Google Search Console and Bing Webmaster Tools.
